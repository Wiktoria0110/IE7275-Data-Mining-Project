## Project Overview
This project builds an automated system that reads hospital patient reviews and predicts whether the patient experience was positive or negative using traditional machine learning classification techniques.

## Problem
Healthcare providers receive thousands of patient reviews but lack efficient tools to analyze them. This project addresses that gap using data mining methods.

## Dataset
- **Name:** Hospital Patient Reviews Dataset
- **Source:** Kaggle
- **Size:** 996 reviews, 3 columns
- **Labels:** 0 = negative, 1 = positive

## Models
1. Logistic Regression
2. Naive Bayes
3. Decision Tree
4. Support Vector Machine (SVM)
5. K-Nearest Neighbors (KNN)
